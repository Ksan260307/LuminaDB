SQL ダンプ (.sql)

                

                  全テーブルの CREATE TABLE と
                  INSERT を 1 つのテキストにします。
                  別のブラウザや別の DB へ移すとき、または変更をファイルとして残すときに使います。
                

              

              
            

            

          


          

            

              
JSON (.json)

              

                全テーブルを { 表名: [行, ...] } の形で書き出します。
                他のツールやスクリプトへ渡すとき向けです。結果セットだけが要るなら、結果ツールバーの
                Export JSON を使ってください。
              

            

            
          

        


        
        

          

            ここに .sql / .csv ファイルをドラッグ&ドロップしても読み込めます
          


          

            

              

                
SQL ファイル (.sql)

                

                  ファイル内の SQL を ; で区切って上から順に実行します。
                  書き出した SQL ダンプを戻すときに使います。失敗した文はエラー内容ごと下に表示します。
                

              

              
            

          


          

            

              
CSV ファイル (.csv)

              

                1 行目をヘッダーとして読み、行を取り込みます。引用符の中のカンマ・改行にも対応します。
                取り込み先に 「新しい表を作る」を選ぶと、ヘッダーから列を作り型を推定します。
              

            

            

              

                
                
              

              

                
                
              

            

            

              
              
            

            
            

              
            

          


          
          

        


        
        

          

            

              
ダミー行の生成

              

                選んだ表の列構成に合わせてダミー行を追加します。件数を増やして、
                索引の効き方や描画の速さを試すのに使います（10 万行まで）。
